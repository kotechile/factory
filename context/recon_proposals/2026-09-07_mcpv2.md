### 1. The Bottleneck & Market Context
- **Current State:** MCP's 2026-07-28 spec is the biggest protocol change since launch — the protocol is now **stateless**. `initialize`/`initialized` handshake is removed, `Mcp-Session-Id` is gone, protocol version + client capabilities move into per-request `_meta`, every request must carry `Mcp-Method` (and `Mcp-Name` for named calls), servers must implement `server/discover`, emit `ttlMs`/`cacheScope`, and the "resource not found" error moved from `-32002` to `-32602`. Roots/Sampling/Logging are deprecated and `tasks/list` is removed. Every existing stateful MCP server has to be audited and rewritten: find session maps, sticky cookies, `Mcp-Session-Id`, reused transport objects, per-connection tool lists — then externalize state to explicit handles and validate per-request headers. Today this is a manual, error-prone, checklist-driven chore with **no deterministic tooling**.
- **Validation Intensity:** Very high repeat intent across 9+ sources; the MCP maintainers themselves shipped a "copy-paste migration checklist." The gap is a concrete, mechanical one: scanning a server for every breaking pattern and producing the v2 form.

### 2. Architecture & Technical Blueprint
- **Engine Type:** Schema Transpiler / Static Scanner + Code Transformer — archetype (b).
- **Deterministic Core (`src/lib/calc/mcpV2Scan.ts`):** pure-TypeScript scanner that ingests an MCP server's source tree (or a JSON spec dump) and reports/patch-writes each breaking pattern:
  - **Break detectors:** `initialize`/`initialized` handshake, `Mcp-Session-Id` emission/consumption, session maps / sticky-session routing, reused transport objects, per-connection tool lists, `tasks/list`, Roots/Sampling/Logging registration, old `-32002` error paths, missing `Mcp-Method`/`Mcp-Name` validation, missing `server/discover`, missing `ttlMs`/`cacheScope`.
  - **Transform outputs:** (1) an audit report scoring `statelessReadiness` 0–100 with per-rule pass/fail + file/line; (2) a generated v2 scaffold (per-request `_meta` parsing, header validation, explicit-handle state contract); (3) a codegen diff for the top patterns.
- **Inputs / Outputs:** `{ repoPath | specJson, ruleset: "2026-07-28" }` → structured JSON `{ score, findings: [{pattern, file, line, severity, fix}], migrated, diff }`.

### 3. Dual-Pronged Monetization
- **Web Tier (Stripe):** free instant scan report (paste repo or upload a recorded MCP session). $9 one-off full migration codegen + diff; $29/mo for a CI hook that flags breaking changes on every MCP server commit.
- **Agentic Tier (WebMCP):** `scan_mcp_server_stateless(repo)` → metered $0.10–$0.25/invocation via Stripe meter. Agent-platform teams call it headless to gate PRs against the 2026-07-28 spec — a deterministic spec-compliance gate is exactly what the new `Mcp-Method`/`Mcp-Name` per-tool WAF rate-limiting world wants.

### 4. Zero-Friction Viral Hook
- **Stateless-Readiness Badge:** a shareable `?repo=` badge/link with the 0–100 score — server READMEs / MCP directories embed it, and every badge is branded attribution → backlink + signup. Position as "the MCP v2 compliance check" the way Lighthouse is for web performance.
